# 行为画像口径统一（2026-11-07）

## 0. 一句话

用 `libriichi/src/stat.rs` 的**同一定义**重算人类凤凰场，得到 **副露局占比 32.63%**，
而 Mortal(S6c) 是 **31.09%** —— 只差 **−1.54pp**。
「Mortal 副露只有人类 2/3、太保守」这个贯穿了 6 周的诊断，**基于错误的 48.26% 基准，不成立**。

## 1. 为什么要做

仓库里"副露率"出现过三个互不一致的数：

| 来源 | 值 | 实际含义 |
|---|---:|---|
| MEMORY §2.5（B/756k 行为对照） | **45.66%** | 未文档化；与本次实测不符 |
| MEMORY §3.15（年度审计） | **5.277 次/半庄** | 副露**次数**，÷8 局 = 0.66 次/局 |
| MEMORY §3.11（S6c 训练期画像） | **31.09%** | `riichi.Stat` 的 `fuuro_rate` |

同一个指标差出 14~15 个百分点，而"模型太保守"这个结论正是靠第三行 vs 第一行比出来的。
**在修尺子之前，任何"改善行为"的改动都缺一个可信的靶子。**

## 2. 口径（唯一真源 `libriichi/src/stat.rs`）

```rust
Event::StartKyoku        => stat.round  += 1;              // 每人每局 +1
Event::Hora { actor }    => stat.agari  += 1;              // 自摸/荣和都算
                            stat.houjuu += 1 (target≠actor) // 放铳记在 target
Event::Reach  { actor }  => stat.riichi += 1;              // 一局最多 1 次
Event::Chi | Pon | Daiminkan if actor == me => fuuro_num += 1;
Event::EndKyoku          => if fuuro_num > 0 { stat.fuuro += 1 }  // **每局最多 +1**
Event::Ryukyoku          => stat.ryukyoku += 1 (4 人各 +1)
率 = 分子 / round
```

⚠️ 两个易错点：
1. **`fuuro_rate` 是「有副露的局占比」（≤1），不是「副露次数/局」**；
2. **副露只算 `chi/pon/daiminkan`，不含 `ankan/kakan`**。

## 3. 实测（`tools/behavior_profile.py`）

- 人类侧：`dataset/mjai/houou4/202[2-5]??/**/*.json.gz`（训练池主体），随机 3,000 文件
- 解析：JSONL 逐行事件（不是 JSON 数组），**126,288 人·局**
- Mortal 侧：直接读 `riichi.Stat` 的输出（`train.py` 的 `behavior:` 行、`ladder.py` 的 `run_meta.json`），**同源，无需重跑**

| 口径 | 和了率 | 放铳率 | **副露局占比** | 立直率 | 流局率 |
|---|---:|---:|---:|---:|---:|
| **人类凤凰场（实测）** | **21.14%** | **12.65%** | **32.63%** | **18.25%** | **16.00%** |
| S6c/956k | 21.67% | 12.27% | 31.09% | 18.55% | — |
| B/756k | 21.92% | 12.86% | 28.26% | 20.05% | — |
| **差距（S6c − 人类）** | **+0.53pp** | **−0.38pp** | **−1.54pp** | **+0.30pp** | — |
| 差距（B − 人类） | +0.78pp | +0.21pp | **−4.37pp** | +1.80pp | — |

自洽性检查：32.63% 的局有副露、0.66 次/局 ⇒ 有副露的局平均 **2.02 次**（吃完还能再碰），合理。

## 4. 三条结论

1. **S6c 的行为画像与人类凤凰场几乎完全对齐**：四项里三项在 ±0.6pp 内，唯一超过 1pp 的是副露 **−1.54pp**（仍 <3pp 容差）。
2. **"弃和不足 / 太保守"的诊断被推翻**：那是拿 S6c 的 31.09% 去比一个不同口径的 48.26%。
   按同口径，S6c 的副露只比人类少 1.5pp——**远小于 ladder 的 ±0.66 分辨率所能支撑的"可改善空间"**。
3. **B/756k 的副露 −4.37pp 才是真实偏离**，而 S6c（+速度特征）把它修到 −1.54pp。
   也就是说 **S6c 已经顺手修掉了这个缺口**，不需要再单独做"加副露"的改动。

## 5. 对路线的影响

| 旧判断 | 新判断 |
|---|---|
| "副露 31% vs 人类 48%，模型太保守" | **伪**（人类同口径 32.63%，差 1.54pp） |
| "下一步增益应提高和了效率/打点" | 和了率已 **+0.53pp**（高于人类），**没有提升空间** |
| "守卫/OG 让模型更保守所以可能更强" | 没有"过度进攻"可修，保守化只是偏离对齐点 |
| 行为侧还有 +3pp 级的可调空间 | **没有**（四项全部 ≤1.54pp） |

**这解释了为什么守卫（λ 重扫）、OG 的 α 退火、B 的"更保守"全都没有收益**：
模型的行为已经在人类分布上，任何"往某个方向推"的改动都是在**离开**最优点。

## 6. 唯一待核实的残留

`流局率`：人类 **16.00%**，Mortal 侧**无数据**（`ladder.py` 的 `run_meta.json` 只写 4 个率，
`train.py` 的 `behavior:` 行也不含 `ryukyoku_rate`）。

MEMORY §2.5 曾记"Mortal 流局 10.9% vs 人类 15.3%"，若同口径成立则是 **−5.1pp** 的真实缺口。
但：**和了 +0.53pp 与放铳 −0.38pp 已经解释了绝大部分"局如何结束"**（两者合计 33.94% vs 人类 33.79%），
流局率若真的差 5pp，剩下的 5pp 必须落在"其他结束方式"（杠流局/九种九牌/切牌流局）上——
这更像是**统计口径差异**而非行为差异。

**建议**：下次跑 ladder 时把 `ryukyoku_rate` 一并写进 `run_meta.json`（一行改动），
就能彻底关闭这个问题；当前不为此单独烧卡。
