2. **高估了“加信息”的收益**：P0 证明主模型 `phi` 的读牌探针 AUC 只有 0.80（A2c 0.97），看起来“缺信息”；但 P1 注入后 A1≈A2 安慰剂——**BC 目标并不需要模型显式知道读牌后验**，人类舍牌已经把风险隐含在行为里。

4. **低估了测量问题**：5000 sets 的 SE≈0.59，根本看不见 +0.3；多个“null”其实是 underpowered。S6c 的 +0.268 是最典型的例子。

## 1. 当前位置：三条坐标

### 1.1 相对自身历史：一个高原，不是一串失败

| 轴 | 代表对照 | 结果 | 结论 |
|---|---|---|---|
| 数据选择/数据量 | R2 / R3 / R4 / R5 / D1 / D2 | R2 **+2.86**；其余 null 或负 | 只有“全体 → top400 + GRP h128”这一大步有效；之后同轴微调大多在 ±0.7 内（D1 −1.40 是负向例外） |
| 奖励/超参 | 消融 A/B/C、hp_ablation | B +0.18（中性基线）；C −5.61；hp 全跨 0 | 奖励形状与超参不是瓶颈 |
| 目标形式 | IQL Stage A / B v1-v3 | A −1.03；B v3 +0.646（CI 跨 0） | MC 局内回传已近饱和，跨局 SNR≈1:10 |
| 表示层（已知/半已知） | S6a / S6c / EV 重排 | S6a +0.182；S6c +0.268；EV 离线冗余 | 重排 obs 已有信息没有明显头部空间；S6c 是唯一“未决正号” |
| 新信息注入 | S6b 四臂 | A1≈A2 安慰剂 | BC 目标不需要显式读牌后验 |
| 决策期塑形 | 守卫 G3 剂量曲线 | **λ=10 +0.778**；λ=20 转负 | **唯一有效的新轴**；最优在人类放铳率附近，不是“越安全越好” |

**读法**：这不是“每个方向都失败”，而是**模型已经站在一个宽阔高原上**：换数据、换目标、换特征大多只能移动 ±0.7；只有 R2 的一次性数据/GRP 跃迁和 G3 的决策规则修正越过了这个带宽。

### 1.2 相对人类行为：进攻接近，防守从过高到略低

| 指标 | 人类 | B/756k 原始 | B/756k + 守卫 λ=10 |
|---|---|---|---|
| 和了率 | 21.17% | 22.28% | 20.7%（同剂量口径 21.7→20.7） |
| 立直率 | 17.69% | 17.94% | — |
| 副露率 | 48.26% | 45.66% | — |
| 放铳率 | 12.55% | **14.05%** | **11.1%**（同剂量口径 13.0→11.1） |
| 流局率 | 15.3% | **10.9%** | —（未记录同口径值） |

> 原始行为画像与守卫剂量曲线来自不同抽样集；守卫列只表示同口径 Δ（21.7→20.7 / 13.0→11.1），**不要与原始列直接相减**。数据出处：MEMORY §2.5 / §3.13。

**解读**：

- 原始模型是**“进攻略多、弃和不足”**：和了率、立直率略高于人类，副露率低 2.6pp，放铳高 1.5pp，流局低 4.4pp。
- 守卫把放铳压到 **11.1%**，低于人类 12.55%；和了率也降到 20.7%，低于人类 21.17%。净效果 +0.78，说明**原始模型的“多进攻”并不划算**；但 λ=20 转负、λ=50 崩，说明最优点在**人类放铳率附近**，而不是零放铳。守卫 λ=10 是否已经越过最优点，需要更细的 λ 曲线（ladder）判断；guarded 锚点只能看粗水平。
- 下一步的增益不应继续加防守，而应提高**和了效率/打点**，让模型在同样风险下多和一点。这也解释了 S6c（自家速度/有效牌）为什么是唯一正号：它正好补的是“进攻效率”这一侧。

### 1.3 相对绝对锚点：目前未知，且 anchor1 不是“部署强度”

**anchor1 现状**（2026-10-26 06:57）：6 进程 × 68 局 = 408 局，Mortal×1 vs akochan×3；已完成 **34/102 sets**，ETA ≈17 h；汇总用 `python agg_anchor.py --dir logs/anchor1`。

三个必须说清的边界：

1. **它测的是未带守卫的 B/756k**。`one_vs_three.py` 的 `MortalEngine` 没有接 `defense_guard`（只有 `ladder.py` 接了）；所以 anchor1 的 avg_pt 是**裸模型**，不是线上默认的 `B/756k + λ=10`。要回答“部署强度”，需要给 `one_vs_three.py` 加守卫钩子后补一个 guarded 锚点。
2. **408 局的 SE≈4.1**（`agg_anchor.py` 用 SD≈82），95%CI 约 ±8。这只能回答“是否明显偏离 0 或某个粗参照”，不能做精细排名；它是 pilot，不是判决。
3. **“uma 同尺度”不等于“人类百分位”**。人类场的 −5.44 / +9.29 是**人类互打**的分布；Mortal 的对手是 3 个 akochan，对手场完全不同。把 Mortal vs akochan 的 avg_pt 直接读成“人类 p95”是**无效推断**。锚点的正确用途是：
   - 作为一个**固定的外部标尺**，比较未来模型（同一 akochan 配置、同一 seed 块）的相对强弱；
   - 作为“能不能稳定压过 3 akochan”的定性判据；
   - 若要谈人类百分位，需要一个人机混合场或人类对手场，当前没有。

**因此，当前位置的“绝对强度”一栏应写成：未知，锚点 pilot 在跑；在 guarded 锚点完成前，不要用 anchor1 的数字给模型定人类档位。**

**另一个陷阱**：**单臂**锚点不能验证守卫的 +0.78——408 局的 SE≈4.1，远大于 0.78；200~400 局的单臂 guarded 锚点同样只能回答“粗水平”。理论上同 seed 的 raw vs guarded **配对**锚点可以消掉牌山方差、把 SE 压到可判范围，但那需要两臂同牌山跑，成本高，而且 ladder 的 64k 半庄剂量曲线已经更直接地回答了这个问题（MEMORY §3.13）。

## 2. 为什么停在 B/756k：五层否证 + 一层例外

| 层 | 试过的变量 | 结果 | 排除了什么 |
|---|---|---|---|
| 1. 数据量/分布 | R3 同池第二 epoch、R4 增强、R5 top200、D1 旧年代、D2 补 2026H1 | R3/R4/R5/D2 null；D1 负迁移 | **不是数据量、不是同分布 reshuffle、不是旧年代增量** |
| 2. 奖励/超参 | 消融 A/B/C、hp cql1/10/aux0 | B 中性、C 显著负、hp 全跨 0 | **不是奖励形状、不是超参没扫对** |
| 3. 目标形式 | Stage A 跨局信用、Stage B 真 IQL（τ=0.7→0.5） | A 显著负；B v3 无结论 | **不是跨局信用、不是 TD 价值传播** |
| 4. 表示层（已知/半已知） | S6a 紧迫度、S6c 自家速度、EV 重排 | S6a null；S6c +0.268（未决）；EV 结构冗余 | **不是“把 obs 里已有的量再喂一遍”**；S6c 补的是 SP 盲区/向听滞后，属半已知 |
| 5. 新信息注入 | S6b 读牌后验（A2c 2 行） | A1≈A2 安慰剂 | **不是“模型不知道读牌后验”**；BC 目标不需要它 |
| 6. 决策期塑形 | 守卫 G3（risk 扣 Q） | **λ=10 +0.778** | **唯一未被排除的轴**：改变决策规则，而不是改变网络/数据 |

**综合解释**：

- **Q 是一个不错的模仿排序器，但 argmax Q 不是风险标定后的决策规则。** 原始模型的放铳率高于人类、流局率低于人类；守卫只改打牌动作，就把 net 拉高 +0.78。这说明“知道哪张更危险”与“按危险程度调整选择”是两件事，后者才是缺口。
- **BC 目标已经把人类的风险偏好编码进行为。** P0 显示主模型 `phi` 的读牌探针 AUC 0.80（A2c 0.97），看起来缺信息；但 P1 注入后行为不变。原因是人类舍牌本身已经隐含了对危险的判断，显式后验是**同源冗余**（MEMORY 坑 72）。
- **局内 MC 已近饱和，跨局信噪比崩溃。** B 基线每局约 16 个决策点、γ=0.997 → 局内折扣 0.997^16≈0.95；终局 pts 的共同分量被 ~190 个决策分享，单决策因果效应 ~±0.1（SNR≈1:10）。所以 IQL 的“更正确的目标”无法转化为可测强度。
- **数据侧的天花板是“信息密度”，不是“文件数”。** R2 的 +2.86 来自“全体 → top400 + 更好的 GRP”，是一次性质量跃迁；之后再加同分布数据、再混旧年代、再补 2026H1，都没有超过噪声。数据侧唯一没试的是**按局内 4 人强度加权**，但 top400 已经过滤过一轮，剩余方差可能不大。

**一句话**：模型不是“训不动”，而是**现有目标 + 现有信息 + 现有决策规则**三者已经互相锁死；能打开锁的只有“换决策规则”（guard）或“换监督/数据权重”（尚未验证）。

## 3. 分辨率账：null 不等于零

| 设计（双向总 sets） | 解析 SE | 2σ 可分辨 | 成本（估） | 能回答的问题 |
|---|---|---|---|---|
| 5000 sets（历史口径） | 0.59 | **1.18** | ≈29 min（5 卡） | 只能判 ≥1.2 的效应；R2 的 +2.86 能看见，+0.3 看不见 |
| 16000 sets（新标准臂） | 0.33 | **0.66** | ≈2~4 h | 能判 ≥0.66；守卫 +0.78 刚好越过 |
| 32000 sets | 0.23 | 0.46 | ≈4~8 h | 能判 ≥0.46；仍看不见 +0.3 |
| 77000 sets | 0.15 | **0.30** | ≈10~19 h | 才能以 2σ 判 +0.3（若真实效应 +0.27，需 ~95k 才稳） |

> 成本按 **500 sets ≈14 分/卡**（MEMORY §2.5）与守卫 16k 两向并行的日志时间戳（约 3 h）估算；4~5 卡并行，机器争用会拉长。旧版按 6.5 h/16k 外推偏保守约 2~3 倍。

**这张表改变了对三个“null”的解读**：

1. **S6c +0.268（CI[−0.76,+1.27]）**：5000 sets 的 2σ 是 1.18，它从一开始就**不可能被判显著**。点估计为正、holdout +0.40pp、新通道使用度 100%/58%，机制也对（进攻效率）——它是**未决的正号**，不是“已否证”。代价是 dqn_loss +3.3%，需要高分辨率复判时一起看。
2. **S6a +0.182**：同样 underpowered，但机制是“重排 obs 已有分数”，属于零新信息；即使真有小效应，也不值得再烧。
3. **奖励 B +0.18**：同理 underpowered，但它的作用是“中性基线”，不是增益；不需要复判。

**决策规则**：

- 16k sets 只用于**先验 ≥0.6** 的候选（守卫类的改进、有明显机制且离线信号强的新规则）。
- 对 +0.3 级候选，只有两种诚实选择：**上 77k sets（~10~19 h）**，或**明确写“未决/underpowered”**，不再写“关闭”。
- 不要再做 5000 sets 的“确认性”判定；它只能用来筛掉明显负向（如 D1 −1.4）。

## 4. 四个候选轴（按先验排序）

### 4.1 A. 价值加权的守卫（最高先验，推理期，无需重训主模型）

**为什么**：守卫 v1 的 risk 只有 `P(放铳)`，没有“放铳后损失多少”。同样是 10% 放铳率，被 12000 点和被 1000 点打到，顺位损失差很多。当前守卫把“危险”与“损失”混在一起，只用概率近似。

**做法**：

- 用冻结的 A2c（或加一个轻量 value head）估计对手**手牌价值/打点期望**：立直状态、dora/宝牌可见数、副露数、巡目、待牌种类；输出 `E[loss_points | deal]`。
- **最低成本版先不训新头**：用规则近似 `E[loss]`（立直=1.0、副露/dora 加成、巡目衰减），只改 `risk_value` 的权重；若规则版离线 frontier 有改善，再训 value head。
- 新 risk：`risk_value(t) = Σ_j P(听_j) · P(待牌_j=t) · E[loss_j | deal]`，再进 `Q' = Q − λ·max(risk_value−τ,0)`。
- 先在 20k 离线样本上扫 λ/τ，看 `deal_top1`、`agari`、`ev_norm` 的 frontier 是否比 v1 更好；只有 frontier 真的外扩，才上 16k 标准臂。

**为什么它不是 EV 重排**：EV 重排用的是 v4 obs 里已有的 SP 表（tenpai/win/EV），只是对已知输入线性重加权，所以 94~99% 排序不变；价值加权的 risk 引入的是**对手手牌价值**这一 obs 里没有的量，属于真正的新信息。

**判据/停止条件**：

- 离线 frontier 不移动（agari 不掉、deal 不降）→ 停；
- 16k 臂 CI 下界 ≤0 → 不采纳，但记录为 underpowered 还是 negative；
- 若 λ 需要调到 20 才有效 → 参考 v1 的教训，大概率过保守，停。

**风险**：价值头误差传播；过度弃和（v1 λ=20 已演示）；A2c 的待牌后验在立直层仍有缺口（MEMORY §3.12-3）。

### 4.2 B. S6c 高分辨率复判（最值得优先结清的“未决”项）

**为什么**：S6c 是训练侧**唯一有机制支撑的正号**（+0.268），机制正好对“进攻效率”缺口；holdout +0.40pp、通道使用度 100%/58% 说明特征真被用上。5000 sets 看不见它是仪器问题，不是模型问题。

**做法**：

- 不重训；用现有 `checkpoints/s6c/mortal.pth`（956k）与 `run_s6c.sh` 的 ladder 阶段，换新种子块（MEMORY §2.4 的下一块 400000/420000），上 **77k sets**（~10~19 h）或至少 32k sets（~4~8 h，仍只能判 0.46）。77 块会占用 **400000~438000 / 420000~458000**，完成后把实际范围写回 MEMORY §2.4。
- 同时记录 `dqn_loss`、`agari`、`deal` 行为画像，确认 +0.27 不是“用 Q 尺度漂移换来的”。
- 若 77k 的 CI 下界 >0：S6c 转正，重新考虑“速度特征 + 守卫”的组合；若跨 0 且点估计衰减到 0（|δ|<0.1）：正式关闭；若跨 0 但点估计仍 +0.2~0.3：标“仍 underpowered”。

**风险/边界**：32k sets 仍可能 underpowered；77k 的成本约等于一轮 180k 步训练（13 h），但它是**唯一能把“未决”变成“确定”**的方式。严格说，若真实效应就是 +0.268，2σ 需要 **~95k sets**；77k 只把 2σ 压到 0.30，仍可能差一点。若 77k 跨 0 但点估计保持 +0.2~0.3，只能写“仍 underpowered”，不能写“关闭”。若不愿意花 ~10~19 h，就把它标为“未决”，不要反复用 5000 sets 重跑。

### 4.3 C. 数据质量加权（唯一未试的数据轴）

**为什么**：R2 的数据选择是“文件级/座位级白名单”，但同一局里 4 个对手的强度仍不同；模型可能在模仿弱对手的坏习惯。D1 显示数据侧变量的效应量比特征侧大一个量级（虽然那次是负的），所以“按局内 4 人强度加权”值得一次探针。

**做法**：

- 用 `player_ratings_2022_2026H1_v3.csv` 给每局算 4 人平均强度/最低强度/最高强度；按强度给样本权重（不是过滤，保持文件集合不变），或按局重采样。
- 先 100k 步探针（B/756k 暖启），holdout 同 digest + 16k 标准臂；不要与 S6c/守卫混在一轮。
- 预期：未知，可能很小；若 `dqn_loss` 变差或 ladder 点估计负，立即停。

**风险**：top400 已经过滤过一轮，剩余强度方差有限；加权会降低有效样本量；GRP 奖励与强度权重的交互未验证。

### 4.4 D. 长期方向（新监督 / 重规划 / 在线，当前不做）

- **RM10 轨迹级监督**：读牌侧唯一的新监督；需要解冻读牌模型，并说明它为何不同于 S6b（S6b 是“注入后验”，RM10 是“换监督目标”）。风险是辅助头绕过主通路（MEMORY 坑 63）。
- **攻防分支重规划（原 S6d）**：在每个决策点比较“继续做牌 vs 弃和”的顺位期望；需要可信的对手后验与更细的分辨率，当前不做；若价值加权守卫转正，可作为下一步。
- **GRP 输入扩展（原 S6d）**：把读牌后验/紧迫度聚合进 GRP 的 7 维输入，提升奖励质量；但 GRP 只见过 2022-2025，且 S6b 证明注入行为不变，优先级低于数据质量加权。
- **在线自博弈 M5**：唯一可能突破 BC 天花板的方向，但评测必须先可信（锚点 + 标准臂），且有已知卡死 bug；P3。
- **不建议现在做**：更多数据量、IQL/Bellman、S6a/c 再编码（除非 S6c 复判转正）、读牌注入、奖励 C、EV 重排、topN 收紧、单纯扩大模型/步数。
