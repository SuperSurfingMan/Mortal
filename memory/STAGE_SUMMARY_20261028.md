## 4. 悬而未决（不要当成结论）

1. **anchor2（S6c+守卫 vs 3×akochan，356 局）= −1.77**，而 anchor1（B，无守卫，408 局）= **+2.87**。
   差值 −4.6（SE≈5.9，0.8σ）⇒ **无统计结论**。两种解释都成立：
   ① 纯噪声；② **守卫在弱对手场里过度弃和**（akochan 远弱于人类场，保守策略反而丢分）。
   要分开需要 ~1700 局（SE≈2）。**这条直接影响「对外部署时是否该挂守卫」。**
2. 守卫在 S6c 上的效应量只有 B 上的 45%——是 S6c 的速度特征替代了部分防守决策，还是 λ 需要重扫？
3. S6c 的两行特征在 `shanten≥4` 时是常数（占 8.7% 决策点），是否存在更细的速度信号空间。

## 7. 追加诊断（2026-10-28 晚）：残差到底是「歧义」还是「分歧」

**先否证一条方法论**：精确重复匹配不可行 —— 76 万打牌决策里**同状态重复组 = 0**；
换成粗键（手牌+轮目+可打牌掩码）也只有 **0.11%** 覆盖（431 组、862 样本），且粗键会
混淆不同「已见牌」的同一手牌 ⇒ **无法用重复组直接估人类噪声地板**。

改用三个可观测替代量（`tools/label_noise_diag.py`，S6c/956k，60,000 打牌决策）：

| 指标 | 值 |
|---|---|
| top1 | 0.7468（202512 训练池内同口径 0.7496 ⇒ 无过拟合，与 holdout 结论一致） |
| **top3 / top5** | **0.9506 / 0.9750** |
| 错误处的 `Q(top1) − Q(human)` | 中位 **+0.722**、p75 +1.475、p90 +2.481 |
| 错误中 \|差距\| ≤ 0.05 / 0.1 / 0.25 / 0.5 的占比 | **4.6% / 8.7% / 21.1% / 38.7%** |
| 按「top1−次优」五分位的准确率 | 0.443 / 0.611 / 0.776 / 0.916 / **0.988** |

**结论（关键）**：残差**不是**「多个合理动作的歧义」——只有 4.6% 的错误落在 0.05 的
近似平局内，中位差距 **0.72**（与该模型典型 Q 边际 1~5 相比是实打实的分歧）。
人类动作有 95% 落在模型 top-3 内，说明模型「看得见」人类的选法，但**更偏好别的**。

推论：
1. **继续追 BC 一致率（top1）价值有限** —— 剩下的错误是模型有主见的不同判断，
   而不是标签噪声；提高一致率最多是把模型拉向人类的平均倾向。
2. 强度提升更可能来自 **有评估能力的改法**：搜索/专家迭代（B2）、或引入能改变这些
   判断的新信息（A1 对手建模辅助任务、A2 风格/对手条件）。
3. 同时也解释了为什么 S6c 只值 +0.42 而不是更多：它改变的是「局部选牌倾向」，
   而那些高置信分歧不是靠再加两行特征能翻转的。

⚠️ 口径说明：本工具在同一数据上给 0.747（202609）/0.750（202512），而 `holdout_metrics`
给 0.8167 —— 两者**采样与过滤口径不同**（本工具取每局全部打牌决策，不排除单位置可打牌
的退化状态）。**绝对值不可与 holdout 直接比，结构结论（top3/top5、错误差距分布、
分层准确率）不受影响。**
