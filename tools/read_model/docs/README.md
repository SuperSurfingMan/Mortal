## 0ter. v2：融合手切时序 + 显式结构估计（2026-10-16 追加）

**动机（v1 的两个结构性短板）**：

1. **时序盲区**：v4 obs 里其实有序码放着每家的牌河（24 槽 × 摸切/立直/dora/被鸣走
   位），但这些信息在**通道维**上，沿列卷积的 ResNet 无法按时间推理——"第 3 巡手切
   5m"与"第 12 巡摸切 5m"只是两个不同的行，`Conv1d(3)` 的感受野跨不过去。而手切
   （tedashi）正是读牌最强的信号：手切说明该牌来自配牌且摸到的牌仍在手里。
2. **逐列边际不自洽**：H1 输出 34 个独立边际分布，无法表达"3 个顺子 + 一个两面搭"
   这类联合结构；H2 只能靠 `g + E[h]` 间接猜形状。

**v2 结构（`model_v2.py`，1.36M 参数）**——三流融合：

```
输入三路：
  A. obs [B,1012,34]     → 与 v1 完全相同的 1D ResNet → h [B,96,34], g [B,96]
  B. tl_tokens/mask      → 每目标家公开动作序列（43 维 token × ≤26 个：
     [B,3,26,43]            牌 one-hot + 摸切标志 + 动作类别(7) + 归一化巡目]
                           → 2 层 pre-norm Transformer（d=64,4头，手写注意力）
                             + attention pooling → e_T [B,3,64]
  C. 结构头（新）        → cat([g, e_T]) → MLP →
                           7 个搭子构造计数软分布（顺子/刻子/对子/两面/嵌张/边张/
                           孤立，各 0..4 分布）+ 3 类形制（normal/七对/国士）
                           + 向听数（8 桶）→ 结构信念 s [B,3,38]

H1 计数分配头（每目标家）：cat([h, e_T, s]) → MLP → 5 类（unseen 掩码）
H2 听牌头（每目标家）    ：cat([g, e_T, s, E[h]]) → MLP → 35 类（+wait_bias）
H3 辅助头                ：cat([g, e_T, s]) → 下一打/向听/立直/鸣牌
损失：L = L_alloc + 0.5 L_wait + 0.2 L_aux + 0.3 L_struct（软 CE + 形制 CE）
```

**结构标签（`structure.py`）**：从真实手牌枚举全部标准分解（顺子/刻子/对子/两面/
嵌张/边张/孤立），按与 Rust `shanten::calc_all` 完全同口径的公式计算向听
（`2L - 2M - min(T+K, L-M) - 雀首修正`，L=4-副露数），标签取**全部最小向听分解**
上的边际直方图（保留真实歧义）。交叉验证：**20.3 万个真实静止态手牌与 Rust 零不一致**
（立直家除外——Rust 把其 shanten 冻结在宣言值，标签用枚举器真值）。

**与 v1 的关系**：空间流/输出语义/训练配置完全一致，`--model v2` 一键切换，
同数据同步数同种子直接对比。

### v1 vs v2 正面对决（2026-10-17，同一固定评估集 20000 样本，bootstrap 200 次）

```

alloc top-1 命中率      0.5658    0.5830   +0.0171  [+0.013,+0.021]   v2优（显著）
立直家待牌 hit@1        0.1239    0.1447   +0.0207  [+0.009,+0.034]   v2优（显著，+17%相对）
听牌检测 AUC            0.6276    0.6855   +0.0579  [+0.053,+0.062]   v2优（显著，最大增益）
wait hit@1              0.1389    0.1464   +0.0075  [-0.001,+0.016]   不显著
wait hit@5              0.4986    0.4900   -0.0086  [-0.017,+0.002]   不显著

```

**结论（统计显著才算）**：
1. **重构有效且方向正确**：时序流+结构流带来三个显著增益——暗牌排序（top-1 +3.0% 相对）、
   立直家待牌点名（+17% 相对）、**听牌检测 AUC 0.628→0.686**。最后一项对防守最有价值：
   "该不该防"比"防哪张"更基础，AUC +0.058 意味着危险/安全样本的区分度大幅改善。
2. **wait 精确点名（hit@1/@5）与 argmin 型防守模拟差异都在 CI 跨 0 的噪声区**——注意：
   60 文件小子集曾给出"v2 全面更差"的相反结论，纯属小样本方差（wait 指标在 ~2500
   样本上方差极大）。**教训：本任务的指标对比必须用固定大评估集 + bootstrap CI**。
3. **结构头本身仍弱**：向听预测 25.7% **低于** 28.4% 的多数类基线（严重低估
   shanten=2/4，对 shanten=0 过预测），形制预测 91.9% = 多数类基线（平凡）；
   真正学到的是"顺子数/孤立数"这类从 tiles_seen 可直接推断的量。也就是说：
   结构瓶颈当前主要靠**时序流**获益，显式向听估计还没学会——这是下一步的主攻方向
   （更长训练 / 向听损失加权 / 分解-向听一致性约束）。**后续**：已由 v2s 实施并
   判决（10-17，见 §0quater：向听 25.7%→52.6%、AUC +0.054、wait hit@1 −1.4pp）。

## 0quater. v2s：结构头专项（2026-10-17 追加）

**动机——v2 结论 3 的机制解剖**。对决后解剖 `train.py`，发现"向听没学会"有两个
机制性原因，而不只是训练量问题：

1. **结构头向听头零监督**：`StructureHead.shanten_head` 的输出
   （`struct_shanten_logits`，即诊断/对决报告里的向听准确率）**没有任何损失项
   引用**——`L_struct` 只有 counts + form；唯一有监督的向听头是 aux 头的
   `shanten_logits`，权重仅 `0.05×0.2=0.01`。且 `s_belief` 瓶颈（38 维）
   **不含向听分布**——向听头处于「只诊断、不馈通、不学习」状态，25.7% 是
   无监督头的随机水平。回归测试 G3e 把这一缺陷存档为门禁（关闭新损失后
   该头梯度恒 0/None）。
2. **形制头不均衡塌缩**：normal ~97%，无类均衡时 form 头 91.9% = 多数类基线。

**改动一览**（`--model v2s`，1.371M 参数；与 v2 同数据同步数同种子直接对比）：

| 改动 | 代码位置 | 默认权重 / 旋钮 |
|---|---|---|
| 向听分布注入结构瓶颈（`s_belief` 38→46 维） | `model_v2.py` `build_model_v2s` | — |
| 结构头向听直接 CE（v2 缺失的一项） | `train.py` `l_struct_shanten` | 0.5 |
| 分解-向听一致性约束（头侧 CE） | `l_consist_head` | 0.3 |
| 分解-向听一致性约束（分解侧 MSE） | `l_consist_decomp` | 0.2 |
| 向听-听牌一致性（shanten==0 ⟺ tenpai） | `l_tenpai_tie` | 0.1 |
| aux 向听 CE 加权 ×3 | `--w-shanten` | 0.05→0.15 |
| 向听/形制类均衡（批内频率逆平方根） | `--no-struct-balance` 关闭 | 开 |

**分解-向听一致性约束**（`structure.soft_shanten_from_counts`）：把预测的 7 个
搭子构造边际分布取期望，代入与硬枚举器同口径的向听公式
`2L-2M-min(T+K,L-M)-雀首修正`（`min` 取次梯度、雀首修正用 sigmoid 软 AND，
全程可微），得到「分解暗含的自洽向听数」。头侧要求向听头预测与该值一致
（target detach，梯度只进向听头——把分解头的判断蒸馏进来）；分解侧要求该
软向听拟合真标签（梯度经公式回流到分解头，让 7 个计数的整体形状承担向听
责任）。**形制门控**：公式与硬枚举器一样只覆盖 normal 路径——实测 normal
形制上 `round(soft)==硬标签` **100%**（mean|d|=0.041，202601 树 9495 个
目标，测试 G1 门禁）；七对/国士的 counts 标签仍是 normal 分解边际、不承载
其向听信息，故约束只作用于 normal 目标。训练侧 `L = 4-副露数` 由公开信息
精确推导（`alloc.sum()//3`，与 dataset 同口径）。

**顺带修复的潜在 bug**：`l_wait` 在整批无心听牌目标时走
`wait_logits.sum()*0`，而 `wait_logits` 含硬掩码 `-inf` → `-inf*0=NaN`
（v1/v2 时代就存在，512 大 batch 几乎必有心听牌目标故未触发；小 batch 边界批
暴露，测试 G3a 门禁）。

**训练**：`bash tools/read_model/run_v2s.sh`（tmux 会话 `read_v2s`，15000 步
同预算）。所有新损失都有 CLI 权重旋钮（置 0 即关闭，便于消融）；best 判据仍是
`alloc_ce + 0.5·wait_ce`（与 v2 同口径，保证对决公平）；旧 v1/v2 checkpoint
不受影响（`struct_shanten_belief=False` 时形状与 v2 逐位一致，已加载验证）。
⚠️ 2026-10-19 更新：best 判据已升级为 **val_score v2**（+ tenpai AUC + 标定项，
RM2/§13.3），v2s 轮当时的 `2.0924` 是旧判据值，与 A2c 的 val_score 比较需注意
版本（ckpt 内 `val_score_version` 字段护航，resume 自动重置 best_val）。

**诊断新增**（`evaluate.py` 结构头段）：向听头准确率 vs 多数类基线 + 逐桶
召回（0..7）、自洽向听（分解暗含）准确率、头↔分解一致率、形制 per-class
召回、结构计数 L1；对决脚本 `compare_v1_v2.py` / `compare_bootstrap.py`
同步加入向听自洽准确率/一致率/形制准确率（bootstrap 给 CI）。

## 0quinquies. A3 规则法基线（2026-10-18）：读牌模型的「vs 人类规则」参照

**定位**（方案 §8.1 第 2 条 / 本文 §10 下一步）：纯 numpy、零学习的人类规则
读牌器——现物/筋/壁 + 立直枚举 + 见逃排除——输出与神经网络同构的
`alloc_probs [n,3,34,5]` / `wait_probs [n,3,35]`，给 A2b（注入基线）提供
「增量 = A2b − 人类规则」的参照系。对 `mortal/` 与 `libriichi/` 零改动。

**实现**（`rule_baseline.py`，约 600 行纯 numpy；唯一 Python 循环是立直枚举的
存在性搜索）：

| 层 | 内容 |
|---|---|
| 硬规则 | 现物/振听（目标家河牌 → 荣和概率 0）；不可表达（4 张全见且自家没有 → 0）；立直枚举（牌池∪{t} 中存在含 t 的完整和牌形 → 支撑集，normal/七对/国士，面子数=4−副露数）；手牌数 = 13−3·副露 |
| 软规则 | 筋（仅前 3 次舍牌：×0.32，立直家 ×0.14——晚切 ±3 无效应，其表观危险全是巡目混杂）；壁（未见 1 张 ×0.75…）；宝牌 ×1.60/邻 ×1.15；中张两端 ×0.85；字牌强巡目依赖（初盘 ×1.05 → 后盘 ×0.20）；舍牌邻接 ×0.90；alloc 倾向（字牌 ×0.45、中张两端 ×0.65、已舍 ×0.38、早切邻 ×0.45、未见梯度 ×0.57/0.82/0.96）→ 逐列二项（w≡1 时与均匀基线逐位相等） |
| 听牌先验 | 分段线性巡目先验（实测饱和曲线）+ 鸣牌 ×1.10/个 + 连续摸切尾长 ×0.35 + 全简单色 flow ×0.80 + 字牌迟打 ×0.35；立直家硬置 1 |

**权重出处**：`calibrate_a3.py` 在**非评估月 202508**（4000 样本）上测各因子的
per-tile 经验比率，冻结为常数；评估月 202609 是严格 holdout。标定推翻/证实了
多个经典先验（见下）。调整权重属「改规则」，需重跑标定并在本表记录。

**与 A2b 正面对决**（2026-10-18，同一 20000 固定评估集，bootstrap 200 CI，
`compare_a3.py`；Δ = rule − net）：

## 2. 数据管线（dataset.py）

**核心思路：4 个 `PlayerState` 同时回放同一事件流。** 观察者 o 的输入 obs 取自其自身
状态（与主训练管线完全同一 `encode_obs(version=4)`）；另外三家的标签直接取自对应
PlayerState 的 `tehai` / `waits` getter——mjai 日志自足，全知标签无需 oracle、
无需 Rust 新增接口。

- **快照时点**：观察者决策点（`cans.can_act()`，与 `GameplayLoader` 样本语义一致）
  + `StartKyoku` / `ReachAccepted` 公告（+ 非杠后 `Dora`）。此时所有目标家都处于
  3n+1 静止态，`waits` 是新鲜值（立直家为冻结值=真实听牌集）。
- **公开信息独立推算**：`tiles_seen` / 各家河 / 立直标志 / 摸牌数全部由事件流在
  Python 侧台账推算（`c_total` = 四家打牌+鸣牌消耗+暗杠+加杠+宝牌指示牌；
  `tiles_seen_A = A 的 tehai + c_total`），逐局重置。正确性由测试 A3 与 obs 内嵌
  的 tiles_seen 通道（第 835 行）逐位比对保证。
- **增广**：万↔筒置换在事件流层面完成（与 `GameplayLoader.augmented` 同语义，
  含 aka 保持 5mr→5pr），obs 与标签一致变换；测试 C 验证等变性。

### 样本字段

| 字段 | 形状 | 含义 |
|---|---|---|
| `obs` | (1012,34) f32 | 观察者 v4 obs（at_kan_select=False） |
| `unseen` | (34,) f32 | `4 - tiles_seen`（H1 容量掩码） |
| `alloc` | (3,34) u8 | 三家暗牌计数标签（tehai） |
| `wait` | (3,35) f32 | **有效荣和集**上的均匀分布（第 35 类=无可荣牌） |
| `next_discard` | (3,) i64 | 下一打（0..33；34=本局无后续） |
| `shanten` / `riichi` / `called` / `tenpai` | (3,) | 辅助标签；`tenpai` 为**结构性**听牌 |
| `turn` / `tiles_left` | () i64 | 巡目 / 牌山剩余（权重与基线用） |
| `river` / `post_riichi_river` / `own_hand` | (3,34)/(34,) bool | H2 掩码输入 |

### 与方案的差异（均有实测依据，见 §6）

1. **输入用 v4 obs（1012 通道）而非新建 ~160 通道特征集**：obs_repr 已包含方案
   §3 清单的绝大部分（四家牌河含手切/立直/dora/被鸣走位、副露、tiles_seen、
   dora 指示牌、点数/顺位/巡目/供托/本场、自家听牌振听），且与主模型训练特征
   完全同源，零新代码零漂移。SP 计算器通道（~119 通道，观察者自身 EV）对读牌
   无用但无害。首层卷积 1012→96 参数 87 万，占比可忽略。
2. **听牌标签 = 有效荣和集** `waits & ~river & expressible`：`PlayerState.waits`
   是结构性听牌集（含自家河里的牌，振听只记在 `at_furiten`），而 H2 的输出语义是
   「打这张牌给他能不能荣和」——按规则河里的待牌永远无法荣和。`expressible` =
   `unseen>0 | own_hand>0`（4 张全在公共区且自家没有的牌没人能打出）。
   掩码与标签按同一口径硬对齐（测试 D1 零冲突）。
3. **河牌硬掩码（所有目标家）**而非方案原文的「非立直家软先验」：河里有待牌即
   振听是硬规则。软惩罚保留为 `hard_river_mask=False` 消融旋钮。
4. **dora 公告快照在紧跟杠时跳过**：实测 dora 事件 100% 紧跟杠，此时杠家处于岭上
   循环中间态（标签不干净）；新指示牌信息在下一个快照必然可见，无信息损失。
5. **快照时点取决策点子集**而非「每个公开事件」：对手摸牌事件不改变公开信息，
   其效果在下一个决策点完全体现在 obs 中；决策点+公告的口径与下游消费时点一致，
   数据量已远超首版需要（813k 局 ≈ 6.6 亿决策样本）。

## 3. 模型（model.py）

```
输入 x [B,1012,34]
  → Conv1d(1012→96,k=3)+BN+ReLU
  → 12 × ResBlock(96)（Conv-BN-ReLU-Conv-BN + 残差 + ReLU）
  → h [B,96,34]，沿列 mean pool → g [B,96]
H1（每目标家一个）：h→[B,34,96] 过 MLP(96→128→5)，unseen 掩码后 softmax → P(h=k)，
                    期望张数 e_j = Σk·P(k)
H2（每目标家一个）：cat([g, e_j]) → MLP(130→128→35)，加 wait_bias 后 softmax
H3（每目标家一个）：cat([g, e_j]) → MLP(128) → 下一打35/向听8/立直/鸣牌
```

三家共享骨干、各自 H1/H2/H3 头（头按相对座位特化——obs 的牌河/副露通道本身就是
按相对座位排布的）。前向签名 `(obs, unseen, wait_bias)`，与 ONNX 导出一致。

## 4. 硬约束层（constraints.py）

推理时后处理（方案 §4.3）：

1. **列内守恒**：`Σ_j e[j,i] ≤ unseen_i`（其余在牌山）；
2. **总手牌数**：`Σ_i e[j,i] == hand_sizes[j]`，由公开信息精确推导
   （静止态 `13 - 3*(吃+碰+大明杠+暗杠)`；加杠净贡献 0）；
   两者用 IPF（迭代比例拟合）联合投影，供给-容量可行性恒成立故收敛；
3. **听牌重归一化** + 立直振听归零入参（`riichi_furiten`，v1 不自动检测）；
4. 立直家手牌冻结由 (2) 的正确 hand_size 自然保证。

## 5. 训练（train.py）

- **损失**：`L = L_alloc + 0.5·L_wait + 0.2·L_aux`；`L_aux = 0.1·下一打 + 0.15·向听
  + 0.025·立直 + 0.025·鸣牌`（辅助头只做表征塑形；向听权重 v2s 起 0.05→0.15 ×3）。
- **结构头专项（v2/v2s）**：`L_struct = l_counts + l_form + 0.5·l_struct_shanten
  + 0.3·l_consist_head + 0.2·l_consist_decomp + 0.1·l_tenpai_tie`，详见 §0quater；
  各权重均可经 CLI 旋钮关闭（置 0）。
- **样本权重**：立直目标 ×3、终盘（巡目≥12）×2、听牌 ×2、开局（≤3 巡）×0.5。
- **课程学习**：阶段 1 仅有立直家 → 阶段 2 中盘（巡目≥4）→ 阶段 3 全量；
  过滤器在 obs 编码**之前**生效（阶段 1 省约 85% 编码开销）。
- **优化**：AdamW lr=3e-4 wd=1e-2 + warmup 5% cosine；**fp32**（遵循项目 AMP NaN
  事故后的决定）；按验证 `alloc_ce + 0.5·wait_ce` 存 best。
- **数据切分**：训练/验证 glob 分离（2022-2025 + 202601-202608 训练，202609 验证）；
  验证集固定文件 + 固定回放 + 均匀抽稀，跨 checkpoint 严格可比。
- **吞吐**：瓶颈在 `encode_obs`（~2.2ms/样本，其中 SP 计算器是大头且对读牌无用）。
  8 workers 实测 ~2.5k 样本/s（与主训练争用 CPU 时更低）。**优化路径**：Rust 侧给
  `encode_obs` 加 `with_sp_tables` 开关（首版不做，避免动共享 .so），或按方案路径 A
  预计算 sidecar 缓存。

- **D 掩码/标签零冲突**；

## 9. Bayes 上界估计（`bayes_bound.py` + `shanten_fast.py`，2026-10-18）

**目的**：A2b 的分层诊断（§10）只说明「未饱和」，不能区分 **(a) 模型没学到** 与
**(b) 可观测信息本身只有这么多**。本实验构造 Bayes 可达性能估计来分开两者。

**三个信息集（tier）**

| tier | 条件化信息 | 求解 |
|---|---|---|
| `counts` | 观察者手牌 + 全部可见牌**张数** | ✅ 精确：未知牌在「三家暗牌（张数=13−3·副露）+ 牌山」上均匀（洗牌⇒超几何），无任何行为假设 |
| `hard` | `counts` + **立直⇒听牌** | ✅ 立直家从 tenpai 手牌流形抽样（完整和牌形−1 张，按 1/#待牌 纠偏） |
| `behave` | `hard` + 舍牌行为似然 | MH（非立直）/ 重要性采样（立直） |

**行为似然**：`L(H)=Π_k P(d_k|H+d_k)`，`P(舍 x|手牌)∝exp(−β·value(x))`，
`value` = 对子/刻子 + 同色 ±1/±2 邻接（ukeire 代理）。语义 = 「打掉的都是废牌」。

**两条被实测否掉的设计（重要，勿重走）**
1. **弃后向听当主信号**：14 张手牌向听对几乎每张舍牌都不退化，无法区分「留住有用
   摸牌」与「打了无用摸牌」，且贵 34×。
2. **完整轨迹滤波**：前向粒子滤波因「手切⇒该牌当时在手里」逐巡死亡（每巡存活
   ~15%，连续 10 次手切 ~1e-8，实测必然全灭）；反向轨迹滤波虽不死，但「被留住的
   摸牌」是隐变量，随机抽样会把 tenpai 手牌组合打散（实测 tenpai 反而 −6 nats）。
   改静态似然后 tenpai vs 随机手牌平均对数似然 **+8 nats（β=1）/ +17 nats（β=3）**。
3. β 在 **202608（非评估月）** 标定：β=1 时后验均值 P(听)≈经验听牌率（1.3×）。

### 11.1 【判决推翻】P(听牌) 不是「过标定」，是「读错了输出」

`L_wait_tenpai = BCE(wait_logits[...,34], 1−tenpai)` 监督的是 **logit**，而全项目
（`evaluate.py`/`strat_metrics.py`/`compare_a3.py`/`bayes_bound.py`/注入设计）用的都是
**softmax** 的 `1 − wait_probs[34]`。两者只在 `Σexp(其余 34 logit)` 恒定时等价，而实测
`logsumexp` 均值 7.81、**sd 1.94** → softmax 把一个与听牌无关的配分函数噪声混进了分数。

| 读法 | mean P(未听) | /实际未听率 0.8536 | tenpai AUC |
|---|---|---|---|
| `1 − softmax(logits)[34]`（**现行口径**） | 0.0836 | **0.098**（= P(听) 过标定 6.26×） | 0.9461 |
| `1 − sigmoid(wait_logits[34])`（**BCE 真正标定的量**） | 0.8516 | **0.998** | **0.9685** |

`sigmoid(l34)` 的十桶可靠性曲线基本贴对角线（[0,0.1)→0.0063 … [0.9,1.0]→0.9975）。
分层重算（困难分层抬升最大）：all 0.9461→0.9685（+0.0224）；`called=1` 0.7748→0.8365；
`riichi=0&called=0` 0.8334→0.8953；**`riichi=0&called=0&turn≥8` 0.6833→0.7799（+0.0966）**。

⇒ **三条既有结论作废/需重判**：
① §10「tenpai_auc 与规则统计打平（0.9461 vs 0.9468，CI 跨 0）」**不成立**：正确读法下
A2b **0.9685** vs 规则 0.9468，差值是原 CI 半宽（±0.0026）的 8 倍。规则法本来就是因子化
输出（`rule_baseline.py:646` `wait_probs[...,34] = 1 − tile_mass`），比较公平。
② §10「困难分层天花板 0.683」+ §9「读侧已近公共信息天花板」的**论据被削弱**：
0.683 是坏读法的产物，正确值 **0.780**；`counts` 档同分层 0.519。「是否真到上界」需用
正确读法重跑 `bayes_bound.py` 才能定论（§9 表内 A2b 列的 AUC 全部要重算）。
③ §9 结论 5 / §13「读牌模型 A2b 收尾」行里写的「注入前必须 Platt/isotonic 重标定 P(听牌)」，**这个 P0 前置消失**：
sigmoid 口径的 P(听牌) 已标定（比值 0.998），可直接当概率注入。

- 跨「探针 ↔ 端到端」的**绝对 CE 不可比**（P1 的 P(t) 是标定的，active 上 `−logP(t)`≈0.74；

- **P3 无增量 ⇒ 注意力机制不是瓶颈，token 内容才是**（见 §11.5-①）。**P2 无增量 ⇒
  规则先验的弱形式不值得做**（但 α 只训 1 epoch，不定论；强形式=枚举硬支撑集未测）。

### 11.4 【规模】训练只用了 4.05% 的一个 epoch

813,145 文件 × 777.8 样本 ≈ 6.32 亿样本；50k 步 × 512 = 2560 万 = **4.05%**。val 曲线到

## 12. 局部手牌信息视角：架构与损失是否充分（2026-10-19）

**触发**：用户提出「实战读牌不要求还原整副手牌，只要能推断出**局部**『很可能有/很可能没有
某个牌型区域』就够；**精确的局部比粗糙的整体更重要**」，并举例「先手切 9s 再手切 7s 立直
vs 先手切 7s 再手切 9s 立直，前者更可能持有 7s 附近的索子张」。要求分析当前架构与损失设计
在这一点上是否充分。

**一句话判定**：用户的核心判断成立且已被量化证实（局部信息确实是 A2b 相对规则法的主要真实

### 12.4 实证②：顺序级——格内分层后，立直层是零

「自然序」= **先切靠边那张**（`d(x)=min(x−1,9−x)` 更小者先切，即外侧先）——这对
**所有 m 都成立，不随 m 翻折**（m=5 两侧对称，剔除）。⚠️ 2026-10-20 审计更正：本节旧版
写「m∈{2,3,4} 自然是内侧先、m∈{6,7,8} 自然是外侧先」，那是把**代码标签的翻折**误当成
**领域规律的翻折**——代码里 `desc/asc` 按**牌号升降**定义（`desc` = 先切 m+1 那张），
而 m≤4 时 m+1 是内侧、m≥6 时 m+1 是外侧，故 `NAT={2:'asc',…,6:'desc',…}` 只是让
「自然」在两套标签间对齐，领域规律始终是「先切靠边张」。
格内（花色 × 中间张，18 格）算 ΔΔ 再按 `min(n外,n内)` 加权 —— 这样每格两组的舍牌
**集合**完全相同。⚠️ 但 A3 规则法**并非顺序盲**（`rule_baseline.py:203,305` 消费

只能称「**规则法地板**」而非「组成混杂上界」（见 AUDIT_20261020.md S1）。
巡目平衡：先切靠边张 11.27 vs 先切内侧张 11.23。

### 12.5 实证③：配对反事实——时序流是空转的

同一样本、**obs 保持不变**，只对调 `tl_tokens` 里 m−1 / m+1 两个 token（n=12636）：

```
回归 measured = a + b·expected ：  b = +0.0144   （b=1 完美，b=0 无响应）
Pearson r = +0.183    r² = 3.3%
外侧先→内侧先(n=6177): measured +0.00255  expected +0.03536  →  7.2%
内侧先→外侧先(n=6459): measured +0.00364  expected +0.02030  →  17.9%
噪声底 ~0.00036/列（三家 Σexp_counts 应恒定），|measured| mean 0.00619
```

⇒ **时序流对顺序几乎零响应**（响应量是噪声底的 17 倍，说明它确实在被用，但语义方向不对：
两组实测 Δ **同为正**）。而 §12.4 显示 A2b 在真实数据上确有显著顺序效应 ⇒
那点效应**全部来自 obs 空间流的按槽牌河通道**。与 §11.5-①（巡目常数）和 §11.3-P3
（加注意力零增量）**三方互证：机制不缺、token 内容是空的。**

### 12.7 判定：架构与损失是否充分

| 维度 | 判定 | 依据 |
|---|---|---|
| 「切了 x ⇒ x±1 不太可能有」的**集合级**局部推断 | ✅ **充分且已学到** | A2b 75~79%，A3 仅 13~19%；CE 增益集中在邻接列（超出规则 +0.0573 vs +0.0367） |
| 「两张开都切了 ⇒ 中间张几近排除」 | 🔶 **半充分** | A2b 49%，A3 方向反；剩 51% 未学到 |
| **切牌顺序**的局部推断（单张 m） | 🔶 **不充分** | 非立直层扣地板后 67%（+0.0256 张）；**立直层（效应最大 0.19 张）为零** |
| **切牌顺序**的区域推断（±2 窗口） | ❌ **不充分** | 三层全部 ≤0，超出地板显著为负 |
| tedashi vs tsumogiri 的区分 | ❌ **不充分** | 真值差 −0.0100，A2b 只 −0.0022（22%） |
| 时序流 `tl_tokens` 作为顺序载体 | ❌ **失效** | 反事实斜率 0.0144、r²=3.3%、两组 Δ 同为正 |

**结论**：架构**能**表达（obs 按槽通道 + k=3 卷积感受野够），损失**没有压力**去学

tile-agnostic pooling），H1 的 per-target 表示**是共享的**（无 per-(target,tile) 顺序特征）。
⇒ **「精确的局部」目前只做到了集合级，顺序级基本没做到。**

**方法学纪律（违反任一条都会得出假结论）**：

1. **counts 精确档是「行为盲地板」而非近似**：`unseen` 池 = 三家暗牌 + 活牌山 + 王牌区
   （−宝牌指示）；目标家 `h_j = 13−3×副露` 张暗牌是该池的均匀随机子集 ⇒
   `P(count_i=k) = C(u_i,k)·C(N−u_i,h_j−k)/C(N,h_j)` **精确**成立（超几何）。
   自检：`Σalloc == 13−3×melds` 100% 一致；`Σunseen − (三家暗牌+活牌山)` ≈ **+13**
   （王牌 14 − 宝牌指示 1）。
2. **一切「模型学到了 X」必须减去地板**：A3 只用牌河**集合**+筋+壁+数牌，天然顺序盲，
   它在同一分层里的 ΔΔ 就是「不用顺序也能产生的表观效应」上界。只有 **A2b 超出 A3 的部分**
   才算真用到顺序。本节 A2b 表观复现率 63% 扣地板后只剩 41%（全样本）/67%（非立直）/−12%（立直）。
3. **合并跨格会引入组成混杂**：「自然序 vs 非自然序」若直接池化，**连顺序盲的 A3 都能
   "复现" 58%**（因为两组的 m 组成不同）。必须**格内算 ΔΔ 再加权**，使每格两组的舍牌集合
   完全相同。
4. **反事实要配逐样本期望**：用池化真值 ΔΔ 当期望会失真（池化值本身可能≈0 ⇒「实现比例」
   分母爆炸）。正确做法：逐样本 `expected = ∓ΔΔ_cell`，再回归 `measured = a + b·expected`
   看 `b` 与 `r²`。
5. **区分「集合级」与「顺序级」**：两者混在一个 CE 里会互相掩盖——本节集合级 75~79% 的
   好成绩，把顺序级 0~22% 的失败完全遮住了。

### 13.7 RM15 显式 order 特征（2026-10-21，20k 探针进行中）

**动机**：RM12 v1（b=0.0131）与 RM14 aux（b=0.0038）都证明「软聚合/可绕过的辅助头」
不会让 tile 通路对齐真顺序。本版直接把顺序做成**可线性读取的通道**：

| 通道 | 定义 |
|---|---|
| `last_v` | 每列 ±2 邻域内**最新 token** 的 embedding（30× 温度 softmax 近似硬选，保持可导） |
| `last_turn` / `last_age` | 上述最新 token 的归一化巡目 / 距快照巡目差 |
| `turn_mean` | 每列邻域内 token 的加权平均巡目 |
| `turn_diff` | `last_turn[m−1] − last_turn[m+1]`（同花色；边界/字牌/缺列置 0）——直接给「左邻先切还是右邻先切」一个标量坐标 |

**改动**：`model_v2.py` 增 `tile_order`（仅 `tl_mode='tile'`）：`tile_proj` 输入从
`2d+1=129` 变 `3d+5=197`；旧 tile ckpt 走 `tile_order=False` 严格加载。

新架构形状/前向），**88 项 ALL PASS**。`run_p1b.sh` 增 `TILE_ORDER=1`（默认 0）。

**20k 探针**：tmux `read_p1b_order_probe`（2026-10-21 08:11 启动，
`mortal/read_model_v2s_a2d_order_probe20k/`，参数量 1,368,400，`tile_order=True`，

若 b 仍 <0.05，说明仅靠输入通道不够，需输入消融/瓶颈（遮 obs 牌河顺序或只喂 tile 图）。
