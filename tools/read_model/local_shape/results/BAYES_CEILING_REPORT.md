# BAYES_CEILING：局部形状的贝叶斯后验与条件熵上限

- 缓存：`/tmp/read_model_diag_cache_a2c/cache.npz`（n=40000；alloc 逐样本校验 PASS）
- MC 子集：6000 快照（seed=20261103；tiers=counts,hard,behave；M=[256, 1024, 4096]；chains=256；iters=128；β=1.0；K≤10）
- counts 精确自检：max|P(a=0) − CPMF0| = 2.98e-08（21 处）
- 口径：P0 的 eval 划分与 mask（`active_any` = 窗口至少一端被目标家手切过；`active_both` = 两端都手切过）；27 类 = 计数截断 0/1/2+。
- `counts` = 精确多元超几何（全量、无 MC 误差）；`hard` = counts + 立直⇒听牌（MC）；`behave` = hard + 舍牌行为似然（MC，构造性近似）。
- **口径限制（重要）**：三 tier 只含「张数 + 立直约束 + 静态舍牌似然」，**不含**牌河顺序/宣言牌/逐巡事件 ⇒ 它是信息**子集**，实测头（A2c/P2c）可以超过它，此时它**不是紧上界**；`prior` 是在评估集上拟合的 oracle （P0 口径），小样本子集（如 riichi/active_both n≈2734）上尤其强，其 `prior_top3` 会显著高于任何模型。
