# 目标改成「超过 A2c」：可行性分析（2026-11-03）

> 结论：
> 1. **用当前 token 特征独立训练：基本不可能（估计 <5%）**。不是训练不够，而是信息集
>    已被 A2c 覆盖，且本模型的偏差方向与 A2c 不一致时**系统性更差**。
> 2. **把 A2c 的 `P(count>0)` 当输入做残差：能做到"不低于"，但预期增益 ≈0**
>    （相关性 0.927、分歧处模型显著更差、混合扫描无增益）。
> 3. **要实质超过（≥1pp），只能引入 A2c 没有的信息**。最现实的是**玩家风格/身份**
>    （A2c 完全不用），其次是行为似然；两者都需要新数据管线，且不保证。

## 0. 先讲清楚"超过"在理论上意味着什么

presence 是 count 的确定性函数：`y = 1[count>0]`。在给定信息集 \(I\) 下，
最优 presence 预测就是 \(1 - P(\text{count}=0 \mid I)\)。

因此：

> **要超过 A2c 的 presence，必须超过 A2c 的 count 后验。**
> 二分类头不能凭空产生更优的后验——它只能换一种参数化去逼近同一个后验。

这条推论决定了三条可能路径：**(A) 新信息；(B) 同一信息下更好的后验估计；
(C) 把 A2c 的后验当输入做残差**。下面逐条用数据判定。

## 1. 路径 B（同一信息、更好的后验）：已测，基本不可能

### 1.1 混合扫描：正交信号 ≈ 0

| 混合权重 w（A2c 占比） | 0.00 | 0.25 | 0.50 | 0.75 | 1.00 |
|---|---:|---:|---:|---:|---:|
| run3 概率混合 AUC | 0.7231 | 0.7305 | 0.7357 | **0.7383** | **0.7383** |
| run3 秩混合 AUC | — | 0.7303 | 0.7355 | 0.7381 | 0.7383 |

最佳混合点恰好等于 A2c 单独。若本模型含独立信息，曲线应在中间出现**高于两端**的峰；
实际是单调收敛到 A2c。

### 1.2 预测相关性 0.927，且"分歧处"模型系统性更差

在 3,913,689 个 informative 单元上：

| 指标 | 数值 |
|---|---:|
| corr(p_model, p_a2c) | **0.9274** |
| 分歧 >0.2 的单元占比 | 5.28% |
| 分歧处 Brier：A2c / 模型 | **0.1853** / 0.2449 |
| 分歧处"模型更接近标签"的比例 | **29.7%** |
| A2c 不确定区（0.25~0.75，占 62.1%）Brier：A2c / 模型 | **0.2311** / 0.2396 |

这比"没有互补"更强：**模型每次显著不同意 A2c 时，七成是模型错**。
残差模型要超过 A2c，必须学会"不要在这些地方 disagree"，也就是退化成恒等映射。

### 1.3 三家联合容量约束：A2c 已经满足

`unseen[x]` 是三家暗牌 + 牌山的剩余张数，故 `Σ_j count_j ≤ unseen[x]` 是硬约束。
逐样本逐牌统计：

| | 违反率 | 平均超出量 | 投影后 AUC 变化（all / cap1） |
|---|---:|---:|---:|
| 本模型 | 0.56% | 0.00246 | +0.0001 / +0.0014 |
| A2c | **0.014%** | 0.000009 | +0.0000 / +0.0000 |

A2c 的 alloc 头已经内建容量掩码；这条"跨目标联合约束"没有剩余信息。

顺带定位到最大局部差距：`unseen==1`（唯一隐藏副本，45.2 万单元）上
**A2c 0.7578 vs 模型 0.7057（−5.2pp）**；但容量投影只补 0.14pp
⇒ 模型的**排序**错了，不是水平没对齐。

### 1.4 数据外推

| 配置 | 数据 | all AUC |
|---|---:|---:|
| run1 d192 无增广 | 40k | 0.7082 |
| run2 d160 增广+正则 | 40k | 0.7153 |
| run3 d224×3 | 120k | 0.7231 |

3× 数据 + 2.8× 参数 ≈ +1.5pp，且 run3 在 2000 步即达峰后下滑（早停）。
按此斜率外推到 500k~1M 大致到 **0.73 附近**，仍低于 0.7383；
而数据成本是现在的 4~8 倍。

### 1.5 既有 Bayes 上界实验的旁证

`docs/README.md` §9（`bayes_bound.py`）：
- `counts` tier（精确超几何，只用可见张数）alloc CE **0.735**；A2c **0.661**；
- 加立直+行为似然的参考读牌器总体打平 A2b（CE 0.755、AUC 0.942 vs 0.965），
  但在 3 个分层落后 ⇒ 参考不构成上界；
- 结论是「A2c 侧没有测出大块可挖空间」。

这与本阶段的结论同向：**公共信息里能被行为/张数解释的部分，A2c 已经拿走了。**

## 2. 路径 C（A2c 当输入做残差）：能"不低于"，但预期 ≈0

- 设计：`logit = a2c_logit + f(tokens)`，`f` 末层零初始化 ⇒ 起点与 A2c 逐位相同；
  早停保证不低于。
- 但 1.1/1.2 已说明 `f` 能学到的正交信号 ≈ 0，且其分歧方向是负的。
- 预期：**+0.0 ~ +0.2pp**（主要是校准/CE 改善，AUC 基本不动）。
- 结论：工程上能"赢"，科学上没有赢；不值得单独开一轮。

## 3. 路径 A（新信息）：唯一有实质空间的方向

按"信息是否真的不在 A2c 输入里"排序：

### A1. 玩家风格/身份（最现实，A2c 完全不用）

- A2c 的 obs 里没有玩家 id；不同玩家的押し引き/留牌习惯差异是真实存在的
  （本仓库已有 `dataset/index/style/*` 与玩家强度榜，说明风格是可测量的）。
- 做法：从 mjai `start_game.names` 取玩家 id，加 embedding（或按历史统计做风格向量）
  到 context；注意 train/eval 同玩家会造成"记忆"，需按玩家切分做一次泄漏检查。
- 预期：**不确定，0.5~2pp**；风险是数据稀疏与过拟合，需要 20 万+ 样本。
- 成本：改数据管线（解析 names）+ 重导出缓存 + 训练，约 1~2 天。

### A2. 行为似然 / 逆规划（已有资产，但证据偏弱）

- `bayes_bound.py` 的 `behave` tier 已有实现（静态价值似然 + MH）。
- 但它的 alloc CE（0.755）比纯 counts（0.735）还差，整体也落后 A2c；
  作为特征能提供的增量预计 **<0.5pp**。
- 若要做，应做成"每张牌一个似然特征"而非整手后验，成本高、收益不确定。

### A3. 跨局/跨半庄的对手历史

- 同一半庄内前几局的行为、以及本次对局的攻防倾向，A2c 的 obs 只有当前局。
- 与 A1 同源，但更容易实现（不需要玩家 id，只需要同一局内的历史摘要）。
- 预期：**0.2~0.8pp**，可作为 A1 的廉价替代先试。

### A4. 更多数据（同一模型）

- 见 1.4：外推到 1M 样本约 0.73，仍不够；不推荐。

## 4. 另一条"能超过"但不属于本线的路：集成

- A2c 多 checkpoint / 多种子平均，通常能 +0.3~0.5pp；
- 这不是"token 模型"的胜利，但如果目标只是"超过 0.7383 这个数"，它最便宜。

## 5. 建议

| 目标 | 建议 | 预期 |
|---|---|---|
| 只是想让数字超过 0.7383 | A2c 多 checkpoint/种子集成 | +0.3~0.5pp，1 天 |
| 想让这条 token 线有价值 | 做 **A3（局内历史）+ A1（玩家风格）**，把新信息喂进 context | +0.5~2pp，不确定 |
| 想稳妥拿到"不低于" | A2c 残差 + 零初始化 | +0.0~0.2pp |
| 继续在当前特征上加结构/加数据 | **不建议**（1.1~1.5 已封死） | ≈0 |

**一句话**：在"公共信息 + 独立训练"这个框里，A2c 已经接近上限，token 模型超过它的概率很低；
要超过，必须换信息源（玩家风格/局内历史），而不是换网络结构。
