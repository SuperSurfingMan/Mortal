# Phase 3：逐牌存在性（Tile Presence）

> 目标：**不预测张数**，只回答「这张牌在不在他手里」——对 3 个目标家各输出
> 34 个二分类概率。输入是观察者自家手牌 + 全场公开信息，结构是
> **牌 token × 动作 token 的双流交叉注意力**。

## 1. 为什么要单开这条线

已有 A2c 读牌模型输出的是每张牌 0~4 张的**计数分布** `P(count=k)`。
P0/P1/P2 证明它的瓶颈在**联合形状**：逐张边缘乘积在 27 类局部形状上只比先验高
0.4~1.4pp，立直层甚至是负的（见 `../local_shape/README.md`）。

本阶段换一个更窄、更直接的问题：

- 下游真正需要的是「他有没有这张牌 / 这张牌是不是听牌」，不是完整的 5 类计数；
- 二分类可以避开计数分布的参数化瓶颈；
- 每张牌单独一个 token、把该牌的**手切/摸切**作为独立动作 token 送进交叉注意力，
  可以让模型显式学「他先切 7s 再切 9s ⇒ 8s 大概率不在手里」这类**顺序证据**，
  而不是把顺序压进一个池化向量。

## 2. 任务口径

- 观察者 o：自家手牌 `own_hand[34]`（已知）+ 全场公开信息；
- 目标家 j ∈ {下家, 对家, 上家}（相对座位 1/2/3）；
- 标签 `y[j, x] = 1[alloc[j, x] > 0]`（全知手牌，只取 0/1）；
- 评估只统计 **informative 单元** `unseen[x] > 0`（`unseen==0` 时四张全可见，
  任何目标家都不可能持有，标签恒 0，纳入会虚高准确率）。

## 3. 两类 token + context

### 3.1 牌 token（34 个 query）

每张牌的「公开履历」22 维（`tokens.TILE_FEATURE_NAMES`）：

- 目标家对它的**手切次数 / 摸切次数 / 是否手切过 / 最早手切巡目 / 最早摸切巡目**；
- 立直后打出次数、最近一次打出的「距快照年龄」、**是否为立直宣言牌**；
- 被鸣牌占用次数、是否在河里、是否在立直后河里；
- 剩余张数 `unseen/4`、自家是否持有、`unseen==0`、`unseen<=1`；
- 是否宝牌 / 宝牌指示牌；
- 对当前立直家的**现物计数、筋计数、平均危险度**；
- 三家河里出现的总次数（可见度）。

### 3.2 动作 token（每家最多 26 个）

目标家的每一条公开动作（打牌/吃/碰/杠/立直），22 维（`tokens.EVENT_FEATURE_NAMES`）：

- **摸切 vs 手切**（这是「顺序证据」的核心位）；
- 动作类型 one-hot、巡目、距快照年龄、立直后、被鸣；
- 被鸣的两张牌；
- 该打牌对当前立直家的**安全度**：现物个数、是否对所有立直家都是现物、
  平均/最大危险度；
- 该牌的剩余张数、是否最后一条动作、位置、是否为立直宣言牌。

### 3.3 context（每家 1 条）

巡目、牌山、立直/副露/手牌数、其他家立直数、「最近打牌里现物比例」、
最近三手平均危险度、自家手牌花色分布、自家宝牌数、总宝牌数、打牌数、手切比例。

### 3.4 危险度与听牌概率

用户提示的两个信号按如下方式注入，都不泄漏标签：

- **危险度**：纯公开信息的启发式（现物 0、筋 ×0.45、幺九 ×0.8、
  `unseen<=1` ×0.7、基值 0.12），对每个目标家 j 的立直对手取均值/最大值。
  动作 token 用它表达「他是不是在打安全牌（弃和防守）」。
- **听牌概率**：`tp_mlp` 先用「动作特征均值池化 + context」预测 `P(tenpai)`，
  作为**辅助任务**训练；推理时 `sigmoid(tp_logit).detach()` 拼进 context，
  并线性投影后加到每个牌 token 上。这样「他有多可能已经听牌」直接调制逐牌判断，
  且是模型自己的预测，不是标签。

## 4. 网络

```
牌 token  [B,3,34,d]  ─┐
动作 token[B,3,26,d]  ─┼─ 2 × CrossBlock ─→ 34 个 logit
context   [B,3, 1,d]  ─┘
```

每个 `CrossBlock`（pre-LN、残差）：

1. 牌流自注意力；
2. 动作流自注意力（padding mask）；
3. **牌流 → 动作流交叉注意力**（牌作 query，动作+context 作 key/value）；
4. **动作流 → 牌流交叉注意力**；
5. 两个流各自的 FFN。

`d=192`、8 头、2 层、dropout 0.1，约 **2.56M** 参数。

## 6. 预注册门禁

在 202609 40000 样本上：

1. `all`：macro AUC ≥ A2c **+0.010**，且 logloss ≤ A2c **−0.010**；
2. `turn>=8`：macro AUC ≥ A2c **+0.010**；
3. `riichi`：macro AUC ≥ A2c **−0.005**（不能明显更差）。

通过 → 可进入注入/风险重排探针；不通过 → 记录证据并停止该结构，
先看分层差距再决定是否调参（不允许直接堆 200k）。

## 8. 结果（2026-11-03）

三次运行（202609 40000 样本，informative 单元 = `unseen>0`）：

| run | 数据 | 参数 | all AUC | turn≥8 | turn≥12 | 立直 | called | vs A2c(all) |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| run1 d192 / lr3e-4 / 无增广 | 40k | 2.57M | 0.7082 | 0.7472 | 0.7565 | 0.7223 | 0.7446 | −0.0300 |
| run2 d160 / aug+sum / drop0.2 | 40k | 1.79M | 0.7153 | 0.7576 | 0.7675 | 0.7364 | 0.7614 | −0.0230 |
| **run3 d224×3 / aug+sum / 120k** | 120k | 5.09M | **0.7231** | **0.7674** | **0.7765** | **0.7397** | **0.7813** | **−0.0152** |
| A2c 基线 `1−P(count=0)` | — | — | 0.7383 | 0.7924 | 0.8078 | 0.7712 | 0.8075 | — |
| prior（逐牌频率） | — | — | 0.5000 | — | — | — | — | — |

**判定：FAIL（未过预注册门禁）→ 关闭「独立 token 读牌」线。**

关键结论：

1. 结构本身有效：all AUC **0.7231** vs 无信息先验 0.5000（**+22.3pp**），
   听牌辅助 AUC **0.9576**（从公开信息预测目标家是否听牌非常准）。
2. 但仍比冻结 A2c 的计数边际低 **1.52pp**（turn≥8 −2.50pp、立直 −3.15pp），
   门禁要求 +1.0pp，差距 2.5pp。
3. **没有互补性**：与 A2c 做概率/秩混合，最佳 0.7383（w=0.75），恰好等于
   A2c 单独；说明本模型的信号是 A2c 的子集，不能当独立增强项。
4. 过拟合是主要瓶颈：run1 在 step 500 即达峰（0.7038）后单调下滑；
   run3 在 step 2000 达峰（0.7177）后下滑。万↔筒置换增广 + dropout + 手牌数约束
   把峰值从 0.708 推到 0.723，但没改变天花板。
5. 推理期手牌数归一几乎不改变 AUC（0.7231 → 0.7232），说明 `Σp=13−3·melds`
   这个硬约束训练时已学到。
6. 逐牌看：差距最小的是万子与 1p（−0.8~−1.2pp），差距最大的是字牌
   （24/28/30/32，−1.9~−2.3pp）——字牌的「可见张数 + 安全牌弃和」证据
   A2c 的完整 obs 读得更细。

**下一步（不在本阶段默认执行）**：若还要用这个结构，唯一有价值的形态是把 A2c 的
`P(count>0)` 作为额外牌特征做残差/蒸馏（需为 train/val 导出 A2c 的 AP），
否则它的信息严格弱于现有读牌模型。

**根因分层归因**（查表基线 0.646、动作流只值 0.94pp、危险度只值 0.15pp、
输出仍是逐牌边际、验证集选择噪声 0.5pp）见
[`ANALYSIS_WHY_BELOW.md`](ANALYSIS_WHY_BELOW.md)。

**「超过 A2c」的可行性**（预测相关性 0.927、分歧处七成是模型错、容量约束 A2c 已满足、
数据外推 ~0.73）见 [`FEASIBILITY_BEAT_A2C.md`](FEASIBILITY_BEAT_A2C.md)。

**A0 分数/局况特征（2026-11-03，已做）**：把 A2c 有而我们漏的当前分数/名次/局数/
本场/供托/亲家/场风补进 context（18→29 维）。**120k 主配置 +0.02pp（zero effect）**，
40k −0.60pp；推理时清零反而 +0.11pp；presence 率在名次/分差上极差只有 0.55pp
⇒ 「缺分数特征」被证伪。详见 [`A0_SCORE_CONTEXT.md`](A0_SCORE_CONTEXT.md)。
